[h1]CAPIE[/h1]
CAPIE (Cyprian's API Extender) is a native library that extends what Hearts of Iron IV mods can do. Rename Anything is the first mod built on CAPIE.

This mod is the switch for CAPIE. It contains no game content: only the switch and one status line in the bottom right corner of the main menu.
[list]
[*]Enabled in your playset: the CAPIE launcher loads CAPIE into the game.
[*]Disabled, or not in the playset: the game starts without CAPIE, as if it were not installed.
[/list]

[h2]The status line in the main menu[/h2]
[list]
[*]"CAPIE 1.4" (the loaded version): CAPIE is running.
[*]"CAPIE missing" in orange: the switch is on, but CAPIE is not loaded. Either the game was not started through the CAPIE launcher, your game version is not supported yet (the launcher then starts the game without CAPIE and tells you), or the main menu has not finished loading yet. CAPIE loads about 20 seconds after the main menu appears.
[/list]

[h2]What you need[/h2]
The CAPIE launcher, set up by the Rename Anything installer (see the release page). Without the launcher this mod does nothing.

[h2]How it works[/h2]
When you press Play, the Paradox Launcher writes your playset to dlc_load.json in Documents\Paradox Interactive\Hearts of Iron IV. The CAPIE launcher reads that file after the game has started. If this mod is listed, CAPIE is loaded once the game reaches the main menu. If the file cannot be read, the game runs without CAPIE and a short notice says so. The game is never held up.

Load order does not matter.

[h2]Multiplayer and achievements[/h2]
While CAPIE is loaded, the game is not declared multiplayer-compatible. Disable this mod in the playset before you play multiplayer.
This mod changes no gameplay files. Whether the game counts it for the checksum or for achievements has not been verified yet.

[h2]Back to the clean game[/h2]
Disable this mod in the playset: the next start is without CAPIE. To remove CAPIE completely, run the installer and choose Uninstall. Saves and other mods are not touched.
